# NMKD upscaling models

NMKD Siax (4×: a universal upscaler for clean and lightly compressed pictures) and NMKD Superscale (4×: sharp results on clean, artifact-free pictures).

Install it on MSE Studio's **Add-ons** page, then pick a model on the **Upscale** page (Model). Upscayl's own model stays the default until you pick another.

## Models

- `4x_NMKD-Siax_200k`
- `4x_NMKD-Superscale-SP_178000_G`
