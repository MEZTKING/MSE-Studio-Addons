# Photo and restoration models

4× models for photos, screenshots and damaged pictures: 4xNomos8kSC, 4xLSDIR, 4xLSDIRplusC, Uniscale Restore and "Unknown" (a model Upscayl once shipped by mistake that people liked).

Install it on MSE Studio's **Add-ons** page, then pick a model on the **Upscale** page (Model). Upscayl's own model stays the default until you pick another.

## Models

- `4xNomos8kSC`
- `4xLSDIR`
- `4xLSDIRplusC`
- `uniscale_restore`
- `unknown-2.0.1`
