# Fast upscaling models

Light, quick 4× models for big batches: Real-ESRGAN General v3 (and its wide-and-deep version) and 4xLSDIRCompactC3.

Install it on MSE Studio's **Add-ons** page, then pick a model on the **Upscale** page (Model). Upscayl's own model stays the default until you pick another.

## Models

- `RealESRGAN_General_x4_v3`
- `RealESRGAN_General_WDN_x4_v3`
- `4xLSDIRCompactC3`
