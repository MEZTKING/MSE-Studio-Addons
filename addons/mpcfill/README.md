# MPCFill

[mpcfill.com](https://mpcfill.com) right inside MSE Studio, on an **MPCFill** page
under Produce.

1. On the page, use MPCFill as you would in your browser: **Import** your decklist
   (or search for cards) and pick the picture you like for each card.
2. Press **Download → XML** on MPCFill. The order comes straight to the panel on
   the right: every card, how many of each, double-faced cards' backs and the
   card back.
3. **Add them to my deck** – they become real cards of your deck, printed with
   the pictures you picked (the Order page and Print at home). **Use its card
   back** makes the order's card back your deck's back.

An order file you saved earlier: **Open an order file…**. The last order is still
there next time.

Pictures come from MPCFill's picture server when it's set (**Picture server…**,
faster and sharper), else straight from the Google Drive they're on. When an
order has two pictures of the same card (different basic land art, say), the
first one is used for all its copies.

Needs MSE Studio 0.16.0 (its built-in browser). Before 2.0 this page searched
MPCFill itself; the website does that better.

## Network

mpcfill.com, only while the page is open (it's loaded the first time you open
the page), and the pictures of an order when you add it. Nothing about your
deck is sent. Orders and pictures are kept in the add-on's data folder.
