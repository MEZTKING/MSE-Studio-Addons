# Anime upscaling models

Real-ESRGAN's AnimeVideo v3 models (2×, 3× and 4×: small and fast, made for anime) and 4xHFA2k (4×, trained on anime art). Upscayl's Digital Art model is still the default.

Install it on MSE Studio's **Add-ons** page, then pick a model on the **Upscale** page (Model). Upscayl's own model stays the default until you pick another.

## Models

- `realesr-animevideov3-x2`
- `realesr-animevideov3-x3`
- `realesr-animevideov3-x4`
- `4xHFA2k`
